# joseph-loffredo.com

Source for Joe Loffredo's academic website, built with [Quarto](https://quarto.org)
and deployed to GitHub Pages by the workflow in `.github/workflows/publish.yml`
on every push to `main`.

    quarto preview   # local live-reloading server
    quarto render    # build into _site/

See `CLAUDE.md` for the file layout, how to add papers or replace the CV, and
known traps.
